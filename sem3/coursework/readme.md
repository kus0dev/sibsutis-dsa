# Coursework

## Task

**Selected Variant:** Task 2, Variant 31 — Dijkstra's and Floyd-Warshall algorithms used to find the shortest path from all vertices to all vertices (All-Pairs Shortest Path).

## Requirements

1. Research and implement in C/C++ the selected algorithms according to the task. Conduct a detailed experimental study of the algorithms, compare their efficiency, and include the results in the report.
2. Write a report according to the template.
3. Create a 3-5 minute presentation reflecting the main information about the algorithms, their efficiency, and applicability depending on the specific dataset. Include the results in the report.

## Implementation Details

- **Language:** C/C++
- **Algorithms:** Dijkstra's algorithm and Floyd-Warshall algorithm.
- **Goal:** Find shortest paths from all vertices to all vertices (All-Pairs Shortest Path).
- **Comparison:** Efficiency based on graph density (sparse vs dense graphs) and number of vertices.

## Experimental Research

- Implement both algorithms in C/C++.
- Compare execution time and memory usage for both algorithms.
- Test on various graphs (sparse vs dense) with different numbers of vertices.
- Analyze the results to determine under which conditions (sparse vs dense graphs) each algorithm performs better.
- Include the results and graphs in the report.

## Deliverables

- Source code in C/C++.
- Report following the template (including experimental results).
- 3-5 minute presentation.
